## What to build

The Persian-first, RTL-first component foundation every later screen is built from — created
before any product screen exists, because the bundle forbids building LTR and converting later
(00 §4; ADR 0010, rejected alternatives). shadcn/ui comes in as owned code copied into
`packages/ui` and adapted to DROP tokens and RTL rules (ADR 0010 D1); it is not an external
design system and the default shadcn identity does not ship.

The tracer-bullet vertical slice: a component gallery route rendering the full Release 0
component set (09 §7) plus the core domain components, entirely in Persian, under
`<html lang="fa-IR" dir="rtl">`, in both dark and light themes, at all three 09 §14
breakpoints — with long Persian titles, mixed Persian/English strings, LTR-isolated IDs and
`DROP FIT`-style controlled English terms in bidi-safe spans. Loading it makes zero network
requests beyond the app's own origin (fonts are local files). That gallery is the demo, the
visual-regression baseline, and the accessibility test target at once.

Key mechanics:

1. **Direction and ownership** (09 §1; ADR 0010 D1/D6). Copy the 09 §7 component set into
   `packages/ui` via the project registry configuration, review RTL output for each, wire the
   shadcn DirectionProvider, and set root `lang`/`dir` in `apps/web/app/layout.tsx`. All shared
   UI uses logical CSS properties; a lint rule makes physical direction utilities
   (`ml-`/`mr-`/`pl-`/`pr-`/`left-`/`right-`/`text-left`/`text-right` and raw physical CSS) a
   build failure in `packages/ui`, with the 09 §1 documented-physical-reason escape hatch as an
   explicit inline disable that names the reason.
2. **Tokens** (09 §3; ADR 0010 D10). Three layers — primitive (charcoal, paper, concrete,
   aluminium, lens-accent), semantic, component — as CSS variables in one theme file, every
   value tagged `PROVISIONAL` until the visual identity application guide lands (open gate,
   17 §5). Exactly one Lens accent token; functional success/warning/danger tokens exist and
   are visually restrained. No component may carry a color literal.
3. **Typography** (09 §5). Vazirmatn bundled under `apps/web/public/fonts` and loaded locally;
   distinct Persian display, Persian body, Latin/system and mono styles; Latin IDs and code
   render inside `dir="ltr"` isolation via a `BidiIdentifier` primitive with a copy action
   (09 §12).
4. **Core domain components** (09 §8, §9; ADR-0015). `PersianDateTime` (UTC stored, Jalali
   Tehran display via date-fns-jalali), `BidiIdentifier`, and the status set —
   `StageStatusBadge` over the 07 §3 stage states, `ProgramStatusBadge`, `ApprovalBadge`,
   `ActorRoleChip`, `BlockerCallout` — each icon-plus-text (never color alone, 09 §13), with
   Persian labels resolved from one central enum-to-label mapping covering the canonical enums
   including the five ADR-0015 additions.
5. **Themes, motion, accessibility** (09 §4, §10, §13). Dark-neutral anchor plus an accessible
   light theme; 120–200 ms feedback motion, no decorative loops, `prefers-reduced-motion`
   honored; visible focus in both themes; WCAG 2.2 AA checks on the gallery.

## Acceptance criteria

- [ ] **AC-12.1 Root direction** (09 §1; 14 §8): the rendered document has `lang="fa-IR"` and
  `dir="rtl"` on the root element with the DirectionProvider configured — asserted in a
  component test and in Playwright on the gallery. `pnpm test:e2e`.
- [ ] **AC-12.2 Owned shadcn set** (09 §7; ADR 0010 D1): every 09 §7 component exists as source
  in `packages/ui`, importable from the package's public API; no runtime dependency on an
  external shadcn distribution; each renders correctly in RTL in the gallery. Unit + snapshot.
- [ ] **AC-12.3 Logical properties enforced** (09 §1; 14 §8): the lint rule fails the build on a
  committed fixture using a physical direction utility in `packages/ui`, and passes the real
  tree; documented-physical-reason disables are inline and carry a reason string. `pnpm lint`
  + rule self-test.
- [ ] **AC-12.4 Token discipline** (09 §3; ADR 0010 D10): one theme file defines all three token
  layers with PROVISIONAL markers; a static scan proves no color literal exists in component
  files outside the theme file; exactly one Lens accent token exists. Static test.
- [ ] **AC-12.5 Local fonts only** (09 §5; 00 §4): Vazirmatn files ship under
  `apps/web/public/fonts`; Playwright records all network requests on gallery load and asserts
  none leave the app origin. Seam 3.
- [ ] **AC-12.6 Bidi isolation** (09 §5, §12; 14 §8): `BidiIdentifier` renders IDs/URLs/code in
  an isolated `dir="ltr"` span with a copy action; mixed Persian/Latin fixtures — including
  controlled terms like `DROP FIT` — render without punctuation or digit reordering. Unit +
  visual snapshot.
- [ ] **AC-12.7 Jalali dates** (09 §12; 05 §2): `PersianDateTime` renders fixture UTC instants
  as the expected Jalali strings in Tehran time, and exposes the raw UTC value for sorting so
  tables never sort by rendered strings. Unit test.
- [ ] **AC-12.8 Status components are enum-exhaustive** (09 §9; ADR-0015): a table-driven test
  renders every canonical value of the stage-state enum (07 §3) and of the ADR-0015 status
  enums through the badge components; each yields icon + central Persian label; an unknown
  value yields the safe fallback with diagnostic, not a crash. Unit test.
- [ ] **AC-12.9 Two accessible themes** (09 §4, §13; 14 §11): dark and light themes both render
  the gallery with passing automated contrast checks on semantic tokens and visible focus
  indicators; axe reports no WCAG 2.2 AA violations on the gallery in either theme. Seam 3.
- [ ] **AC-12.10 Reduced motion** (09 §10; 14 §11): under `prefers-reduced-motion`, nonessential
  transitions are absent — asserted by component test on a motion-bearing component. Unit/Seam 3.
- [ ] **AC-12.11 Visual baselines** (09 §14; 14 §13): committed Playwright snapshots of the
  gallery at 1440x1000, 1024x768 and 390x844 covering long Persian titles, mixed-direction
  content and LTR IDs; any clipped diacritic or mirrored icon found during review is treated
  as release-blocking per 09 §14. Seam 3.
- [ ] **AC-12.12 Checks green** (16 §7): `pnpm typecheck && pnpm lint && pnpm test &&
  pnpm test:e2e && pnpm build` pass.
