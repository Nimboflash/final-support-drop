# Ticket 0.15 — Release 0 audit sweep

## What to build

Not a feature — a verdict. This ticket runs Release 0 against its own definition of done and
produces the evidence bundle the human owner accepts or rejects at the gate (00 §8, 14 §14).
The exit criteria audited here are the RESTORED set per ADR-0011: the four criteria silently
dropped from the source plan are back in force, and the "Program" criterion is audited at its
decided meaning — versioned Project/Program rows exist via schema+API (ticket 0.4/0.7 scope)
while the Program creation flow is verified ABSENT, because it belongs to Release 1.

Demoable when done: the seven-step Release 0 vertical demo (15 §2) replays from one script on a
clean environment, every exit-criterion checkbox below has attached machine-verifiable evidence,
and the human owner receives a go/no-go recommendation they can interrogate line by line.

## Blocked by

All other Release 0 tickets: 0.1-0.14 and 0.16 (added by ADR-0014).

## Acceptance criteria

### Restored Release 0 exit criteria (15 §2 as amended by ADR-0011)

- [ ] A Project and a Program exist as versioned rows created through schema+API; the Program
      creation FLOW is absent from the product surface (ADR-0011) — Seam 2 + Seam 3 negative.
- [ ] An artifact, a workflow version and a run can be created and versioned — Seam 1 + Seam 2.
- [ ] Published workflow versions and approved artifact versions reject in-place edits at both
      HTTP and DB seams (14 §4) — Seam 2 + pnpm test:db.
- [ ] Two seeded users with different roles see permission-correct Persian UI with no data
      leakage (15 §2) — Seam 3.
- [ ] The generic workflow editor and execution view persist beyond browser refresh and full
      browser-state loss (15 §2, 08 §17) — Seam 3.
- [ ] Missing provider leaves the manual product usable: dashboard functional, affected stages
      in WAITING_INPUT with reason PROVIDER_CONFIGURATION_REQUIRED (ADR-0012, 13 §5) — Seam 1 +
      Seam 3.
- [ ] Redis flush in test loses no durable work: reconciler reconstructs READY|QUEUED|
      FAILED_RETRYABLE dispatch from PostgreSQL; no duplicate stage results/events/artifacts
      (07 §7, 14 §6.10-.11) — Seam 1 drill with logs in the evidence bundle.
- [ ] RESTORED (ADR-0011): mock structured output validates against its schema and is stored as
      an artifact version with validation record — Seam 1.
- [ ] RESTORED (ADR-0011): a failed run is visible in the run views with per-stage states —
      Seam 2 + Seam 3.
- [ ] RESTORED (ADR-0011): prompt versions used by a run resolve from configuration (registry
      publication per ADR-0015), never hardcoded, and appear in the frozen manifest (07 §6) —
      Seam 1.
- [ ] RESTORED (ADR-0011): a disabled user's sign-in is blocked, their sessions are revoked, and
      their historical attribution remains intact (14 §9) — Seam 2 security test.

### Sweep additions (15 §2 ticket 0.15 row)

- [ ] Workflow validation: the complete 14 §5 suite is green, one failing fixture per 07 §13
      publish check — workflow definition tests.
- [ ] Pro-license gate: REACT_FLOW_PRO_LICENSE_CONFIRMED=false in every committed config and a
      repository scan finds no React Flow Pro source (08 §1) — scripted repo scan + config test.
- [ ] RTL/accessibility: all 14 §8 automated checks green; WCAG 2.2 AA automated checks plus the
      manual keyboard review of 14 §11 recorded as evidence — Seam 3 + axe.
- [ ] Tenant isolation: cross-workspace resource enumeration and access attempts fail for every
      resource type shipped in R0 (14 §9) — Seam 2 security suite.
- [ ] The seven-step vertical demo (15 §2) runs as one scripted e2e, with step 5's approval
      flowing through the approvals endpoint only (ADR-0013) — pnpm test:e2e.

### Repair-ADR audits

- [ ] State machine drill (ADR-0012): a run is paused from RUNNING, resumed, a stage is skipped
      via condition-false and via governed manual skip, and a second run is cancelled from a
      non-terminal state; run-level statuses match the aggregation rule — Seam 1 matrix.
- [ ] Approval integrity (ADR-0013): gate verbs rejected as run commands; a minimum_approvals: 2
      gate rejects the same actor twice at the endpoint and at the DB constraint; MACHINE/SERVICE
      deciders rejected — Seam 2 + pnpm test:db negative tests.
- [ ] SSE coverage audit (ADR-0014): for every persisted transition exercised in the drills, a
      corresponding stream event was observed, including run.completed, run.failed,
      run.cancelled, run.paused, run.resumed, stage.skipped, stage.cancelled and heartbeat;
      afterSequence resume verified — Seam 2 SSE audit script.
- [ ] Status enum audit (ADR-0015): projects, programs, weekly_lenses, requests and
      calendar_items have enumerated status vocabularies in packages/contracts, enforced at the
      DB layer, and no UI renders an out-of-vocabulary status — contract tests + pnpm test:db.
- [ ] Supply chain (ADR-0016): a clean full build (images + packages) completes from the
      mirror-capable configuration of the doc 13 amendment with no direct pull from Docker Hub,
      npmjs or browser CDNs recorded in the build log — build log attached as evidence.
