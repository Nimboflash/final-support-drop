## What to build

The tracer bullet for the whole build system: one repository in which every later ticket can
compile, lint, and test through frozen command names. Create the pnpm workspace exactly as laid
out in (05 §3): `apps/web` (Next.js App Router with standalone output) and `apps/worker`, plus
the thirteen packages named in the 16 §3 master prompt — `core`, `studio`, `contracts`, `db`,
`pipeline`, `workflow-ui`, `ai-gateway`, `retrieval`, `storage`, `ui`, `config`,
`observability`, `testing`. That thirteen-package enumeration (16 §3, matching 05 §3) is the
contract for this ticket and supersedes any smaller package count in earlier source arithmetic;
record the supersession in the ticket handoff as a deviation note.

Each package is a safe placeholder: a typed export, a trivial passing Vitest test, and a
`tsconfig` extending the strict shared base. Wire the dependency rule from (05 §4) into
tooling — an ESLint boundary rule or dependency-cruiser config — so that the allowed direction
(`contracts <- core/studio <- pipeline <- app adapters`; `ui <- web`; `workflow-ui <- web`)
compiles, and each forbidden import (core/studio importing Next.js, domain code importing
provider SDK or React Flow types, ui importing domain services, components importing Drizzle)
fails the checks. Prove both directions with minimal fixtures (16 §3).

Establish the root scripts `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm test:db`,
`pnpm test:e2e`, `pnpm build` (16 §7). These names are frozen here; later tickets must not
invent variants. `test:db` and `test:e2e` may be inert until tickets 0.4 and 0.13 populate them,
but the scripts must exist and exit 0 so CI wiring never changes shape.

Create the root `CLAUDE.md` per (16 §2): pointers to the frozen Master Build Spec v1.0, Project
Master Document, Spec V0, Execution Plan, Brand DNA v3.0, this implementation pack and ADR 0010;
the non-negotiables from (00 §4); the package dependency rules; the requirement to stop at
release gates. Per ADR-0011, it must also state the governing authority hierarchy — the
DELIVERY_README order, to which 00_READ_ME_FIRST §3 defers — and flag that ruling as pending
human-owner ratification, so no later session silently re-litigates precedence.

**Demoable when done:** a fresh clone runs `pnpm install && pnpm typecheck && pnpm lint &&
pnpm test && pnpm build` green; deleting a package or adding a forbidden import turns the run
red.

## Blocked by

None — can start immediately. (This is the doc 16 §3 first-session ticket.)

## Acceptance criteria

- [ ] **AC-1** From a clean clone, `pnpm install` then `pnpm typecheck && pnpm lint && pnpm test && pnpm test:db && pnpm test:e2e && pnpm build` all exit 0 with exactly those script names (16 §7). *Seam: repository check seam.*
- [ ] **AC-2** A workspace-integrity Vitest test asserts the workspace contains exactly `apps/web`, `apps/worker`, and the thirteen packages of (16 §3) — no more, no fewer — by reading `pnpm-workspace.yaml` and package manifests. *Seam: workspace-integrity test.*
- [ ] **AC-3** Every package and app extends the shared strict tsconfig (`strict: true`); a test walks all `tsconfig.json` files and fails on any opt-out of strictness. *Seam: workspace-integrity test.*
- [ ] **AC-4** Dependency-direction fixtures compile for every allowed edge in (05 §4), and the boundary rule rejects each forbidden import class (domain -> Next.js, domain -> React Flow types, ui -> domain services, component -> Drizzle) — verified by fixtures that are expected to fail lint/typecheck. *Seam: dependency-direction tests + repository check seam.*
- [ ] **AC-5** No package contains business-domain behavior: placeholder exports only, no Machines 01-05 logic, no provider code, no secrets (16 §3). *Seam: independent review checklist (16 §8) — recorded in handoff.*
- [ ] **AC-6** Root `CLAUDE.md` exists with all 16 §2 required pointers, the 00 §4 non-negotiables, dependency rules, the release-gate stop rule, and the ADR-0011 authority hierarchy statement with its pending-ratification flag. *Seam: a test asserts the file exists and contains the required section headings; content review in handoff.*
- [ ] **AC-7** `pnpm-lock.yaml` is committed and no manifest uses floating `latest` ranges (05 §2); a lint script greps manifests for forbidden range specifiers. *Seam: repository check seam.*
