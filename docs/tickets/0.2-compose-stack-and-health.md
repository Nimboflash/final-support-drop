## What to build

The tracer bullet for operations: the same seven services the production reference deployment
uses (13 §2), running locally from one `docker compose up`, with health semantics that every
later ticket can rely on. This is the first slice of the "Iranian infrastructure first,
self-hostable always" principle (13 §1) made executable.

Compose defines nginx (TLS termination point, static policy), web (Next.js standalone), worker
(BullMQ), postgres, redis, minio and backup. All configuration flows through `packages/config`
with Zod validation (05 §8), split into required platform configuration (database, Redis, S3,
auth secret/origin, keys, proxy/TLS) and optional live-AI configuration (13 §4). Absent AI
config must leave the platform ready-with-degraded-AI, because manual mode is a non-negotiable
(00 §4).

Implement `/health/live`, `/health/ready`, `/health/deps` per (13 §5) with the exact readiness
rules listed above; the worker gets a container healthcheck. `/health/deps` carries diagnostic
detail and is therefore internal-only at this stage.

Preview isolation starts here as policy and topology, before any preview content exists:
a distinct origin/host rule for `/preview` in nginx, a restrictive CSP distinct from the
dashboard CSP, cookie scoping that keeps dashboard session cookies away from the preview origin,
and a reserved restricted bucket/prefix in MinIO configuration (05 §11; 13 §8). Ticket 0.14
builds the storage behavior on top of this policy.

Apply ADR-0016's supply-chain repair as build configuration, not prose: every image reference
in compose and Dockerfiles takes a configurable registry prefix (defaulting to a mirror
variable), pnpm resolves through an overridable registry via `.npmrc`, the Playwright browser
download host is pinned to a variable, and fonts/assets remain locally bundled (13 §9). The
repo gains a check script that fails when a hard-coded Docker Hub/npmjs/CDN reference is
introduced. The operational mirror procedure itself is documented in the doc 13 supply-chain
amendment recorded by ADR-0016; this ticket makes the build obey it.

**Demoable when done:** `docker compose up` on a clean host, then the smoke script shows green
live/ready checks; stopping postgres flips readiness; stopping redis leaves web readable;
building with `REGISTRY_PREFIX` pointed at a mirror succeeds without touching docker.io.

## Acceptance criteria

- [ ] **AC-1** `docker compose up` from a clean checkout starts nginx, web, worker, postgres, redis, minio and backup; the smoke script gets HTTP 200 from `/health/live` and `/health/ready` through nginx (13 §2, §5). *Seam: compose smoke.*
- [ ] **AC-2** Dependency toggles behave per (13 §5): with postgres stopped, `/health/ready` is non-200; with redis stopped, web `/health/ready` still 200 and `/health/deps` reports degraded dispatch; with MinIO stopped, readiness for file operations is reported unavailable; with AI env unset, status is AI-degraded while ready stays 200 (13 §4). *Seam: compose smoke (scripted stop/start assertions).*
- [ ] **AC-3** packages/config tests: boot with a required variable missing exits non-zero with a named validation error; boot with only platform config (no AI config) succeeds; server-only values are never exported to browser-public config (05 §8). *Seam: config unit tests.*
- [ ] **AC-4** The preview origin is isolated: smoke assertions show `/preview` responses carry the restricted CSP, differ from the dashboard CSP, and dashboard cookies are not scoped to the preview origin; the restricted MinIO prefix/bucket is present in config (05 §11; 13 §8). *Seam: nginx config seam + compose smoke.*
- [ ] **AC-5** ADR-0016: the supply-chain check script passes — every image reference uses the configurable registry prefix, `.npmrc` honors the registry override variable, the Playwright download-host variable is set, and introducing a hard-coded `docker.io`/`registry.npmjs.org`/CDN URL makes the script fail (negative fixture committed). A full `docker compose build` succeeds with the prefix pointed at a non-default value. *Seam: supply-chain check seam.*
- [ ] **AC-6** No secret value exists in git: `.env` files are gitignored, `.env.example` documents every variable without real values, and the secret-scan step in the smoke/CI script passes (13 §9). *Seam: repository check seam.*
- [ ] **AC-7** `/health/deps` requested from outside the compose network via nginx is denied; from inside it returns diagnostic detail (13 §5). *Seam: compose smoke.*
- [ ] **AC-8** `nginx -t` passes in CI; request/body limits and named rate-limit zones for auth, upload and run-command route groups exist in the committed config (13 §9). *Seam: nginx config seam.*
